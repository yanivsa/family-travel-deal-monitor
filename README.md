# Family Travel Deal Monitor

Public hourly monitor for exceptional family travel deals during Chol HaMoed Sukkot 2026.

Family: 2 adults + 3 children (ages 10, 7, 2).
Hard travel windows only: 27/28 Sep 2026 outbound and 1 Oct or 2 Oct morning return.

The repository publishes a public dashboard through GitHub Pages and runs an hourly GitHub Actions monitor. Live provider adapters must use official/authorized access and secrets supplied through GitHub Actions; the monitor never fabricates unavailable data.
